# How to Use This Repo With Coding Agents

Point a coding agent at one pattern folder and ask it to adapt the pattern into
your project. Each v1 pattern keeps docs, reference code, tests, and fixtures in
one folder so the implementation context is local and portable.

Recommended prompt:

> Use `patterns/01-tool-privilege-broker` as the reference. Implement the same
> pattern in my project using the local architecture and add equivalent tests.
