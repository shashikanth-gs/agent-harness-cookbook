# What Is an Agent Harness?

An agent harness is the layer around an agent that makes its capabilities
explicit, bounded, observable, governable, testable, auditable, and adaptable to
the risk of the use case.

It is not the model, not the agent framework, and not necessarily a production
platform. It is the set of controls and design choices that determine what an
agent can do, how risky actions are handled, what evidence is captured, and how
behavior is evaluated over time.
