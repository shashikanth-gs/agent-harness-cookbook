# What This Does Not Solve

- It does not make vector similarity an access-control mechanism.
- It does not guarantee that authorized documents are truthful or unpoisoned.
- It does not replace prompt-injection containment for retrieved text.
- It does not solve stale indexes without lifecycle and cache invalidation.
- It does not prove every answer claim is supported by citations.
- It does not manage enterprise entitlements by itself.

Residual risk remains when source metadata is wrong, index updates lag behind
deletions, citation validation is shallow, or downstream agents treat evidence
as authority.
