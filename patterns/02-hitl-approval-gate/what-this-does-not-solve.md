# What This Does Not Solve

- It does not guarantee a human makes the right decision.
- It does not replace tool policy.
- It does not replace audit.
- It does not make vague evidence meaningful.
- It does not protect actions that bypass the approval gate.

Residual risk remains when reviewers lack context, identity data is stale,
approval UI hides important fields, or graph branches can reissue rejected
actions.
