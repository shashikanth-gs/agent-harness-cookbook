# What This Does Not Solve

- It does not detect every injection variant.
- It does not make untrusted content safe by labelling alone.
- It does not replace the tool privilege broker.
- It does not replace retrieval authorization.
- It does not prove that a skill file, MCP server, or tool package is safe.
- It does not validate every memory promotion policy.
- It does not solve all multi-agent information-flow risks.

Residual risk remains when malicious content is subtle, when tool policy is
overbroad, when traces omit intermediate events, or when downstream systems
execute actions outside the harness boundary.
